How the four models differ

Vanilla RNN

  • cell=rnn
  • torch cell: nn.RNN
  • no gate: the hidden state is overwritten each step

GRU

  • cell=gru
  • torch cell: nn.GRU
  • update + reset gates decide what to keep

LSTM

  • cell=lstm
  • torch cell: nn.LSTM
  • input/forget/output gates plus a cell state

Improved LSTM

  • cell=lstm
  • torch cell: nn.LSTM
  • same cell, more capacity + dropout 0.4
